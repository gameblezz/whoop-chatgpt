Privacy Policy

Last updated: September 22, 2026

Kanasin WHOOP ChatGPT is a personal integration intended to allow the account owner to access and analyze their own WHOOP data through an AI assistant.

Information Accessed

With the user's explicit authorization, the application may access WHOOP data permitted by the scopes selected during authorization, including profile, body measurements, physiological cycles, recovery, sleep, and workout information.

How Information Is Used

WHOOP data is used only to retrieve, display, summarize, and analyze the authorized user's personal fitness and wellness information in response to their requests.

Data Sharing and Sale

This application does not sell personal information. The hosting provider processes data needed to run the application. When you explicitly enable AI chat, the selected WHOOP measurements, dates, and your chat messages are sent to OpenAI to generate a response. Profile names, email addresses, and WHOOP identifiers are removed from the measurement snapshot before it is sent. Information you type into chat is sent as written.

The application requests store: false from the OpenAI Responses API. This does not guarantee zero retention: provider abuse-monitoring and other applicable retention policies still apply. See OpenAI data controls. Viewing your dashboard or raw WHOOP data does not send it to OpenAI.

Data Storage and Security

OAuth access and refresh tokens are encrypted at rest on the application server. The server also stores the WHOOP user ID, hashed session identifiers, CSRF values, and short-lived hashed OAuth state. The encryption key and API credentials are kept in server environment settings, separate from the database and source code. Login sessions expire after seven days and OAuth attempts after ten minutes. Tokens remain until you disconnect, delete them, or the authorization becomes invalid.

WHOOP health records and chat history are processed in memory and are not written to the application's database or request logs. Chat history is kept in the current browser page only and is cleared on refresh or using the clear-chat button. The operator is responsible for protecting hosting infrastructure, disabling sensitive proxy logs, and managing backup retention. Deleted records may remain in backups until those backups expire.

User Control

Disconnect in the application to revoke WHOOP access and delete all locally stored tokens and sessions for your account. Logging out deletes only the current browser session. If WHOOP is unavailable, the local-delete option removes stored credentials and sessions; you should then revoke access in WHOOP settings yourself. You can also revoke access directly in WHOOP settings at any time. Clearing a conversation does not delete any copies held by service providers under their policies.

Contact

For privacy questions regarding this personal integration, contact the application owner using the contact information provided in the WHOOP Developer application configuration.

Changes

This policy may be updated as the integration changes. Updates will be published on this page with a revised date.
